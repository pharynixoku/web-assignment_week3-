# OKUU CYBER Budget Tracker – Week 3

## Project Description

This project is a Personal Budget Tracker developed as part of the Week 3 CSS Visual Identity assignment.

I improved the Budget Tracker created in the previous weeks by adding a consistent color palette, custom Google Fonts, improved table and form styling, and better use of the CSS Box Model.

## Features

- Personal Budget Tracker heading
- Add Expense form
- Expense category dropdown
- Expense table with sample records
- Budgeting tips video
- How-to-use section
- Responsive design for smaller screens
- Styled buttons and form inputs
- Alternating table row colors
- Hover effects

## Visual Design

### Color Palette

The project uses a simple and consistent color palette:

- Blue – primary color for buttons, headings, and table headers
- Teal – section headings
- White – cards and form areas
- Light gray – page background
- Dark blue/gray – main text

### Typography

Two Google Fonts are used:

- **Montserrat** – used for headings and important titles
- **Open Sans** – used for body text, labels, forms, buttons, and table content

This font combination improves readability and creates a clear visual hierarchy.

## CSS Box Model

The project uses the CSS Box Model through:

- **Margin** – creates space between different sections.
- **Padding** – creates space inside cards, forms, buttons, and table cells.
- **Border** – separates and defines different elements.
- **Border-radius** – gives cards, inputs, buttons, and sections rounded corners.
- **Box-shadow** – gives the main sections a card-like appearance.

## Table Styling

The expense table includes:

- Table headers
- Borders
- Cell padding
- Alternating row colors
- Hover effects
- Styled table header

The table contains columns for:

- Name
- Amount
- Category
- Date

## Form Styling

The Add Expense form contains:

- Expense name
- Amount
- Category
- Date
- Add Expense button

The form inputs have consistent spacing, borders, rounded corners, and focus effects.

## Files

### index.html

Contains the structure of the Budget Tracker, including the header, Add Expense form, expense table, help section, video, and footer.

### style.css

Contains all visual styling, including colors, fonts, spacing, borders, buttons, table styling, responsive design, and CSS Box Model properties.

### budget-logo.png
